# gowarp (deprecated)

gowarp generated Cloudflare WARP+ keys, stored them in MongoDB, and served them
through a web page and a CLI. It no longer works: Cloudflare blocks the
key-generation method it relied on, and using that method is no longer
permitted.

The code is removed from `master` and the repository is archived. The last
version with code is commit
[`74861cf`](https://github.com/handsomefox/gowarp/tree/74861cf), kept for
reference only.
